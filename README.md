# 🌌 紫荆壁纸 Pro

Zijing Wallpaper

一个基于 GitHub Pages 的液态玻璃风格壁纸展示平台。

---

## ✨ 项目介绍

紫荆壁纸是一款面向手机和电脑端的壁纸平台。

采用：

- 液态玻璃 UI
- 星空视觉效果
- 响应式布局
- PWA 应用结构

打造沉浸式壁纸体验。

---

## 🚀 当前功能

✅ 壁纸展示

✅ 壁纸分类

✅ 壁纸收藏

✅ 壁纸下载

✅ AI壁纸入口

✅ 用户中心

✅ PWA 手机安装支持

✅ GitHub Pages 自动部署
